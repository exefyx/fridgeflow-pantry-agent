# FridgeFlow · 冰箱食材管家

FridgeFlow 是一个本地优先的家庭食材管理与用餐规划 Agent。它根据冰箱库存、保质期、可用时间和饮食偏好生成具体的一餐，并将缺少的材料自动加入购物清单。

无需账号、后端、API Key 或付费额度。

## 核心功能

- 记录食材名称、数量、单位、分类、保质期和存放位置
- 自动识别已经过期与三天内到期的食材
- 按全部、快过期和新鲜状态筛选库存
- 根据库存匹配程度、到期紧迫度、制作时间和饮食偏好推荐菜品
- 展示食材就绪率、缺少材料与推荐原因
- 标记菜品已制作后自动扣减库存
- 将缺少的食材一键加入购物清单
- 购物项目勾选、删除和已购买清理
- JSON 档案导入和导出
- localStorage 本地持久化
- WebMCP 工具支持 Agent 查看库存、添加食材和生成用餐建议
- 桌面端、平板和手机响应式界面

## Agent 逻辑

FridgeFlow 的推荐分数综合考虑：

1. 当前库存覆盖了多少菜品材料
2. 能否优先消耗三天内到期的食材
3. 菜品是否符合用户选择的时间上限
4. 菜品是否符合清淡素食或高蛋白偏好
5. 仍需采购的材料数量

推荐过程完全在浏览器中完成，结果透明可解释。

## 本地预览

```bash
python -m http.server 8030 -d dist
```

打开 `http://127.0.0.1:8030`。

## 技术

原生 HTML、CSS、JavaScript、localStorage、规则评分与 WebMCP。项目没有运行时依赖，也不会把用户的库存或饮食信息上传到服务器。
